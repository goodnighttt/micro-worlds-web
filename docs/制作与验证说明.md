# 微观世界网页 v01

日期：2026-09-07。独立网页项目，原三个 Blender 项目没有混放、移动或覆盖。

## 页面与交互

参考用户提供页面的淡绿底色、左侧文字、中央箱庭、右侧昼夜与操作栏、左下场景卡；未使用参考截图中的视频播放器、账号、品牌素材。页面名称为「微观世界」。

Three.js 实时三维：神社、樱花车站、水世界三场景；正交相机、近远景平滑切换、拖动环顾、滚轮及双指缩放、左右旋转、重置、全屏与动画暂停。窄屏改为上下布局。昼夜用日光、月光、环境光、实际局部光源、自发光和泛光连续过渡。

神社以六座石灯笼照亮石阶；车站包含候车灯、路灯、夜樱补光、随电车移动的车头光及红黄绿信号自发光；水世界保留暖窗、灯火、冷色月光，并在网页增加轻微海面波动。车站电车采用网页端 30 秒进站、停靠、离站循环，信号服务视觉叙事。暂停冻结电车与海面时间，镜头与昼夜仍可操作。

## 工程与资源

- 神社来源：`01_神社_木漏日/Komorebi_Shrine_Animated.blend`，第 1 帧。
- 车站来源：`02_樱花车站/Sakura_Station_Animated.blend`，第 280 帧。
- 水世界来源：`03_水世界漂浮堡垒/Water_Fortress_AssetWorld.blend`，第 1 帧；不是竖屏细节短片版。
- 网页实际资源：`public/worlds/{shrine,station,water}.glb`，贴图内嵌；同名 JSON 保存镜头、灯光、源工程与版本。
- Draco 解码文件随网页本地提供，无外部 CDN 依赖；压缩保留细部几何，贴图最高 1024 像素。
- `scripts/export_worlds.py` 用 Blender 5.1 生成新夜景工程、低成本试图及网页资源。先另存再导出，原工程保持完整。它是工作区构建脚本，需要原三个项目。
- `scripts/compress-worlds.mjs` 压缩资源并重新解码检查；原始 GLB 位于 `intermediate/raw-glb/`，不进入发布包。
- `scripts/verify-worlds.mjs` 解码并检查三场景的顶点有限值、索引范围、材质、灯光、相机与电车分组。

## 夜景 Blender 版本

各源项目第一层新增 `*_WebNight_v01.blend`，保留原模型与原动画。三张试图分别保存到各项目 `intermediate/Web_Night_v01.png`。800×800、24 fps、Cycles 12 采样加降噪；这些是验证图，不是已批准静帧交付。没有渲染完整新动画。

## 实现边界

网页 GLB 使用指定帧的求值模型，烘焙原修饰器与人物姿态；未迁移 Blender 的完整人物骨骼动画、风动形态键和全部程序化材质。网页电车、信号与水波由实时逻辑驱动；人物仍是原场景姿态。水世界跨楼层回家、进屋睡觉和清晨出门暂缓，属于用户明确允许暂不实施的可选项。不能将人物静态展示称为完整作息系统。

程序化噪声材质简化为原材质基色，直接图像贴图保留。网页视觉与 Cycles 渲染不会逐像素一致。手机采用较低像素倍率，但仍需支持 WebGL 2。

## 检查记录

已检查三张 Blender 夜景试图。类型检查、生产构建、Draco 解码与几何验证用于网页交付；几何结果见 `intermediate/geometry-verification.json`。页面非浏览器 HTTP 请求确认可返回 200。未进行浏览器截图或点击验收，实际帧率、设备差异和最终艺术效果仍需用户体验确认。
